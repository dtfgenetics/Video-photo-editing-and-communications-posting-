# Creator Engine / THC Content Engine — Source of Truth

`dtfgenetics/Video-photo-editing-and-communications-posting-` is the canonical code, schema, recipe, tool, test, and packaging repository for the Creator Engine / THC Content Engine.

Google Drive `08 Automation/THC Content Engine` is canonical for human project controls, approved brand kits/assets, example approved outputs, release packages, and operational records that do not belong in source control.

ChatGPT Library `DTF Working Projects/04 Automation/Video editing social program` is a working/recovery surface only.

## Product rules

- Clean exports are the default.
- Original input media remains untouched.
- No forced watermark or forced branding.
- Social/API connections are optional.
- Secrets, OAuth tokens, webhooks, private media, generated customer packages, and customer data must never be committed.
- Tools and workflows must follow the repository schemas/recipes rather than one-off hidden behavior.

## Current milestone

MVP v0.1 is the Clean Posting Package Engine. It should create validated multi-format exports, thumbnail, caption/hashtag/posting-note files, and a package manifest/ZIP from supported input media.
